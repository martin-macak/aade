# The cold reader sees only SKILL.md. Each question has one expected answer.
Q: When may an agent start to collect sources for a research?
A: Only after the user approves the brief, which the agent records with `$R status <slug> brief.md final`; the agent must not research before that approval.

Q: How does an agent add a source to the register of a research?
A: Only the command $R source add writes an entry in sources.md, and it prints the new source ID.

Q: How does a file cite a source, and what writes the footnote definitions?
A: The file puts a footnote reference such as `[^S2]` right after the claim, and `$R cite sync <slug>` writes the footnote definitions at the end of the file.

Q: What must each item of `## Key findings` in the report contain?
A: Each item must cite at least one primary source or end with (unverified), and the check enforces this from status review on.

Q: What must follow every Mermaid diagram in a research artifact?
A: A prose paragraph that explains what the diagram shows and why it matters. The check fails a diagram without it in every status.

Q: Which files does `$R init` create, and where?
A: It creates the files brief.md, report.md and sources.md in docs/research/<slug>/.
